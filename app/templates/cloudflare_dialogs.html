Configure Cloudflare API

Create an API token with access to the domains you want CNC to manage.

  1. Open Cloudflare API tokens ↗ and choose Create Custom Token.
  2. Add these permissions:
Zone · ZoneRead
Zone · DNSEdit
Zone · SSL and CertificatesEdit

Under Zone Resources, include only the zones you want to use. Create the token, then paste it below.

Configure Cloudflare Tunnel

  1. Open Cloudflare Tunnels ↗ and create a Cloudflared tunnel.
  2. Open Add a replica and copy the Tunnel token from the installation command.
  3. After connecting, add your hostnames under Published application routes, with service {{ cloudflare_tunnel.service_url }}. Cloudflare creates DNS for each hostname; existing address records can conflict.
